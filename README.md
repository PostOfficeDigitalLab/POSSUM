# POSSUM

POSSUM is a PODLAB transcription tool for subtitle and editorial exports.

## Download

[Download for Mac — Apple Silicon & Intel](https://github.com/PostOfficeDigitalLab/POSSUM/releases/latest/download/POSSUM-macOS-universal.zip)

Extract the ZIP and move POSSUM.app to Applications. Models download on first use. Release notes list the version and compatibility details.

[Release notes and older versions](https://github.com/PostOfficeDigitalLab/POSSUM/releases) · [PODLAB](https://podlab.tv)

This repository contains distribution documentation and release assets. Application source code is not included.
